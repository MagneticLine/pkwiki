# 页面类型

- `Profile`：长期个人画像和稳定偏好。
- `LifeEvent`：具有时间属性的重要个人经历。
- `Project`：软件、申请、学习或职业项目。
- `CareerMaterial`：简历、申请、证书和职业材料索引。
- `Reflection`：反思、复盘和思想演化。
- `Decision`：关键选择、理由、约束和结果。
- `HealthRecord`：健康、体检和基因检测记录。
- `PsychologicalPattern`：经确认的长期心理或行为模式。
- `LearningNote`：课程、书籍、论文和技术学习记录。
- `Concept`：可复用的外部知识概念。
- `Timeline`：跨页面的事件时间线。
- `SourceSummary`：大型 Source 的长期入口，不替代 Extracted Source。

不确定页面类型时，先保留候选类型并请求 Human Maintainer 确认。
