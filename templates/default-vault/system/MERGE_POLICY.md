# 合并策略

## Vault 目的

把会影响未来理解、建议、决策或长期复用的个人经历和知识，沉淀为可追溯的 Wiki。

## 优先保留

- 能改变对 Human Maintainer 理解的信息。
- 重要经历、选择、失败、反思和目标变化。
- 长期偏好、规则、边界、喜好和厌恶。
- 与已有 Wiki 补充或冲突的信息。
- 未来可复用的学习、职业和申请材料。

## 可以延后

- 需要更多上下文或 Human Maintainer 确认的内容。
- 当前无法合理定位页面的信息。
- 高敏且写入价值不明确的信息。

## 可以舍弃

- 已有更好记录的明显重复。
- 纯格式噪音。
- 与 Vault 目的无关且没有长期价值的信息。

所有重要 Information Item 都必须记录 merged、deferred、discarded 或 needs_confirmation，舍弃必须写明原因。
